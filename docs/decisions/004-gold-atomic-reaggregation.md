# 004. Gold 영향 날짜 완전 재집계

## 상태

확정 (날짜 미기록)

## 배경

지연 이벤트와 퍼널 변경은 이미 생성된 과거 Gold 결과를 수정한다. 행 단위 증감 계산은 재실행과 삭제 상황에서 오류가 누적될 수 있다.

## 결정

- 이벤트 기반 Gold는 영향 `event_date`, 퍼널 기반 Gold는 영향 `funnel_date`를 완전히 재집계한다.
- 해당 `summary_date` 파티션을 Iceberg predicate overwrite로 원자적으로 교체한다.
- 전체 재구축은 `overwritePartitions()`를 사용한다.

## 이유

- 같은 입력을 다시 실행해도 결과가 수렴한다.
- 재계산 결과가 0행인 날짜도 기존 파티션을 제거할 수 있다.
- 서로 다른 날짜 축과 grain을 명확히 유지할 수 있다.

## 포기한 대안

- 기존 Gold 값에 delta를 더함: 재시도, 수정, 삭제에서 중복 또는 잔존 데이터가 생길 수 있다.
- 모든 날짜 전체 재구축: 영향 없는 파티션까지 다시 읽고 쓴다.

## 결과와 번복 조건

Gold가 커져 날짜 단위 재집계도 SLA를 넘을 때 더 세밀한 grain이나 추가 사전 집계를 검토한다.
